# BOOK

Use the current project's knowledge map and conversation to decide where to start an explanation and what to cover.

1. Start at the nearest relevant known boundary and skip material the user already understands. Use the conversation where the map is silent.
2. When a missing causal link is blocking the user, explain that link first, then continue the task.
3. Update the boundary only when the user's reasoning, application, or correction supports a change. An explanation, a brief acknowledgment, or moving on is insufficient. Narrow an overstated entry and keep any broader understanding still supported by the evidence.
4. Save only short knowledge labels that change what a future explanation would cover or skip. Keep routine updates invisible and show the map when asked.
